# 计算器插件 🧮

> 一个带历史记录的输入式计算器，专为 Naimo Tools 平台开发

## 功能特性

- ✅ **输入式计算** - 直接在输入框输入数学表达式
- ✅ **实时预览** - 边输入边显示计算结果
- ✅ **历史记录** - 自动保存计算历史，支持查看和管理
- ✅ **记录管理** - 删除单条记录或清空全部
- ✅ **快速复用** - 点击历史记录快速填入表达式
- ✅ **完整运算** - 支持加减乘除、括号、百分比
- ✅ **亮色主题** - 清爽的白色主题设计
- ✅ **本地存储** - 历史记录持久化保存

## 使用说明

### 基本用法

1. **输入表达式** - 在输入框中输入数学表达式
2. **实时预览** - 下方会实时显示计算结果
3. **按 Enter** - 将表达式和结果保存到历史记录
4. **查看历史** - 所有计算记录都会显示在下方列表中

### 快捷键

| 按键    | 功能                   |
| ------- | ---------------------- |
| `Enter` | 保存当前计算到历史记录 |
| `Esc`   | 清空输入框             |

### 历史记录操作

| 操作         | 说明                       |
| ------------ | -------------------------- |
| **点击记录** | 将表达式填入输入框继续编辑 |
| **悬停显示** | 显示删除按钮               |
| **点击 X**   | 删除单条历史记录           |
| **清空全部** | 删除所有历史记录（需确认） |

### 支持的运算符

| 运算符     | 说明   | 示例             |
| ---------- | ------ | ---------------- |
| `+`        | 加法   | `12+34` = 46     |
| `-`        | 减法   | `100-25` = 75    |
| `*` 或 `×` | 乘法   | `8*7` = 56       |
| `/` 或 `÷` | 除法   | `100/4` = 25     |
| `( )`      | 括号   | `(10+20)*3` = 90 |
| `%`        | 百分比 | `50%` = 0.5      |

## 计算示例

### 基础运算

```
12+34 = 46
100-25 = 75
8*7 = 56
100/4 = 25
```

### 复杂表达式

```
(10+20)*3 = 90
100*(1+0.1) = 110
50+20*2 = 90
(100-20)/4 = 20
```

### 百分比计算

```
50% = 0.5
100*50% = 50
200+10% = 0.2
```

### 小数运算

```
0.1+0.2 = 0.3
3.14*2 = 6.28
10/3 = 3.3333333333
```

### 历史记录项

每条历史记录包含：

- **表达式** - 灰色小字显示原始表达式
- **结果** - 蓝色大字显示计算结果
- **删除按钮** - 悬停时显示，点击删除该记录

## 技术特性

### 开发技术栈

- **TypeScript** - 类型安全的开发体验
- **Vite** - 快速的开发和构建
- **TailwindCSS** - 现代化的样式方案
- **LocalStorage** - 持久化历史记录

### 核心功能

1. **表达式解析** - 支持标准数学表达式
2. **安全计算** - 严格的输入验证
3. **精度处理** - 自动处理浮点数精度问题
4. **实时反馈** - 输入即显示结果
5. **历史管理** - 完整的增删查功能
6. **本地存储** - 数据持久化保存

### 数据持久化

- 使用 `localStorage` 保存历史记录
- 自动加载上次的历史记录
- 最多保存 100 条历史记录
- 支持清空和删除操作

## 使用场景

### 1. 快速计算

输入表达式，实时看到结果，按 Enter 保存。

### 2. 查看历史

所有计算都会保存，可以随时查看之前的计算。

### 3. 复用表达式

点击历史记录，表达式会填入输入框，方便修改和重新计算。

### 4. 管理记录

可以删除单条不需要的记录，或清空全部重新开始。

## 注意事项

1. **历史限制** - 最多保存 100 条历史记录
2. **本地存储** - 历史记录保存在浏览器 localStorage
3. **清空确认** - 清空全部时会弹出确认对话框
4. **精度限制** - 结果保留 10 位有效数字
5. **字符限制** - 只能输入数字和运算符
